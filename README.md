## Getting Started

First, run the development server:

```bash

# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.

## Auth configuration

- Set `API_BASE_URL` in your environment (e.g. `.env.local`) to your backend URL (default `http://localhost:3000`).
- The login endpoint must return `{ data: { original: { token } } }`. The token is saved as an httpOnly cookie named `jkfc_token`.
- `/dashboard` is protected via `middleware.js` and requires the token; otherwise users are redirected to `/login`.
- Use `app/lib/api.js` for authenticated server-side requests. It automatically adds `Authorization: Bearer <token>` to outgoing requests.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
